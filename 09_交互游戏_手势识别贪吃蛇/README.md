# 手势识别贪吃蛇

## 一句话介绍

基于 OpenCV 和手部关键点识别，用摄像头捕捉食指位置来控制贪吃蛇移动，实现一个人机交互小游戏。

## 技术栈

- Python、OpenCV
- cvzone、HandTracking
- NumPy、JSON

## 功能流程

```mermaid
flowchart LR
    A[摄像头输入] --> B[手部关键点检测]
    B --> C[提取食指坐标]
    C --> D[更新蛇头方向]
    D --> E[碰撞与得分判断]
    E --> F[最高分JSON保存]
```

## 我负责的具体贡献

- 使用摄像头实时读取画面，提取手部关键点。
- 将食指坐标映射为游戏控制输入。
- 实现蛇身移动、食物生成、碰撞判断、得分和最高分保存。
- 通过该项目学习 OpenCV 实时交互和小游戏状态循环。
