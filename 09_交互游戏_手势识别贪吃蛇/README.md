# 手势识别贪吃蛇

我使用 OpenCV 与手部关键点识别，将摄像头中的食指坐标映射为贪吃蛇实时控制输入。

## 技术栈

- Python、OpenCV
- cvzone、HandTracking
- NumPy、JSON

## 功能流程

```mermaid
flowchart LR
    A[摄像头输入] --> B[手部关键点检测]
    B --> C[提取食指坐标]
    C --> D[更新蛇头方向]
    D --> E[碰撞与得分判断]
    E --> F[最高分JSON保存]
```

## 我负责的具体贡献

- 使用摄像头实时读取画面，提取手部关键点。
- 将食指坐标映射为游戏控制输入。
- 实现蛇身移动、食物生成、碰撞判断、得分和最高分保存。
- 串联 OpenCV 实时视觉输入与游戏状态循环，完成连续帧交互和状态更新。

## 运行方式

cd "09_交互游戏_手势识别贪吃蛇"
