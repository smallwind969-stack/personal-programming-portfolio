# 房间布局可视化

一个无需后端的浏览器端房间布局工具。它使用同一套房间和家具参数生成三维视图、俯视图、正视图与侧视图，可用于家具试摆和空间关系检查。

## 功能

- 拖动旋转三维场景，滚轮缩放。
- 在四种视图间切换，并保持参数同步。
- 调整家具位置、尺寸、旋转角度及显示状态。
- 校准房门、卫生间门和窗户的位置与尺寸。
- 检查家具越界、几何重叠及卫生间占地冲突。
- 导入和导出布局 JSON，导出当前视图 PNG。

## 运行

直接用浏览器打开 `房间设计.html`。若浏览器限制本地模块加载，可在目录中启动静态服务器：

```bash
python -m http.server 8000
```

随后访问 `http://localhost:8000/房间设计.html`。

## 技术栈

HTML、CSS、JavaScript、Canvas 与 Three.js。该工具是空间试摆原型，不是施工 CAD，也不应替代现场尺寸复核。
