# 智慧工地安全帽检测系统（基础版）

我实现了 PyQt5 图像检测界面、OpenCV 图像读取、华为云 API 请求签名和检测结果解析。

## 技术栈

- Python、PyQt5、OpenCV
- 华为云机器视觉 API
- APIG SDK

## 我负责的具体贡献

- 完成基础窗口、图片加载和检测按钮交互。
- 实现云 API 请求签名与结果解析。
- 将图片检测链路扩展为后续的视频检测版本。

## 与云 API 版的区别

| 项目 | 基础版 | 云 API 版 |
|---|---|---|
| 输入 | 主要面向图片/简单测试 | 面向视频、摄像头和抽帧 |
| 界面复杂度 | 简单窗口 | 更完整的播放、截图、结果展示 |
| 工程成熟度 | 学习验证 | 可展示原型 |

## 运行说明

```bash
cd "06_计算机视觉_智慧工地安全帽检测系统_基础版"
python main.py
```
