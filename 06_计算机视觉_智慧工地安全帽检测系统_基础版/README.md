# 智慧工地安全帽检测系统（基础版）

## 一句话介绍

这是安全帽检测项目的早期课程实践版本，用于学习 PyQt5 界面、OpenCV 图像读取和华为云 API 调用的基本流程。

## 技术栈

- Python、PyQt5、OpenCV
- 华为云机器视觉 API
- APIG SDK

## 我负责的具体贡献

- 完成基础窗口、图片加载和检测按钮交互。
- 学习并实践云 API 请求签名与结果解析。
- 为后续“云 API 版”视频检测系统积累界面与接口调用经验。

## 与云 API 版的区别

| 项目 | 基础版 | 云 API 版 |
|---|---|---|
| 输入 | 主要面向图片/简单测试 | 面向视频、摄像头和抽帧 |
| 界面复杂度 | 简单窗口 | 更完整的播放、截图、结果展示 |
| 工程成熟度 | 学习验证 | 可展示原型 |

## 运行说明

```bash
cd "06_计算机视觉_智慧工地安全帽检测系统_基础版"
python main.py
```
