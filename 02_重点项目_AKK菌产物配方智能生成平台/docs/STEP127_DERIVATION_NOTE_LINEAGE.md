# STEP127：结构化派生数据的转换说明

## 交付内容

- 上传结构化派生文件时，除选择原始设备文件外，还可填写“转换说明”；
- 说明会随资产保存为 `sourceConversionNote`，并在文件资产的来源链路中展示；
- 典型说明包括设备专用格式的解密工具版本、导出步骤、编码转换或人工校对方式；
- 服务端禁止没有来源文件却填写转换说明，避免产生无法审计的孤立描述；
- 批量上传与单文件上传使用相同的持久化与来源校验规则。

## 验证记录

- 中文转换说明的服务端专项用例通过；
- 新增无来源说明拒绝用例，返回 HTTP 422；
- 浏览器验证：首次接入页面选择来源文件后，转换说明输入框出现；
- 仅用于界面验证的两个隔离实验及其未引用对象已在停止服务后清理，不会留在实验归档中。
