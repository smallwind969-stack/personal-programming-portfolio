# STEP126：首次数据接入的原件关联入口

## 交付内容

- 首次数据接入工作台会读取当前实验中等待设备适配的原始文件；
- 上传转换后的 CSV、TXT、TSV 或 XLSX 时，可在同一页面选择“转换来源”；
- 选中后会把 `sourceAssetId` 与结构化文件一并提交，服务端建立不可跨实验的派生关系；
- 新上传的原始二进制文件会立即加入可选来源列表，研发人员无需跳转页面；
- 转换文件解析后自动清空选择，避免误复用上一次来源。

## 验证记录

- 前端类型检查和生产构建通过；
- 创建隔离实验 `exp-0cebdd116b38` 并上传 `first-use-device.raw`；
- 浏览器实际验证首次接入工作台出现“转换来源（可选）”选择器，且列表中展示该 RAW 文件；
- 该链路与 STEP121 的服务端来源校验、STEP122 的删除保护、STEP125 的建模资产边界共同构成完整数据接入闭环。
