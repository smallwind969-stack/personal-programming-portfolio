# STEP104 普适产线业务上下文

## 目标

把行业与产线差异从平台核心流程中分离出来，让实验明确记录所属产业、工艺类型、产线装置、物料体系和关键参数，为后续按企业动态生成仿真结构与优化变量打基础。

## 本步完成

- 新增实验级产线业务上下文，并随实验记录持久化。
- 新建实验增加所属产业、工艺类型、产线或装置名称、物料体系和关键工艺参数。
- 实验总览展示已锁定的业务上下文，不再依靠实验名称猜测行业。
- 使用“精细化工 / 连续混配 / 进料流量 / 釜温 / 黏度”验证非菌藻配置能够完整保存和读取。
- 菌藻示例显式登记为“生物制造与功能食品 / 菌藻培养与发酵”，仅作为隔离演示行业模板。
- 旧实验缺少该字段时使用中性默认值；旧版示例在读取时恢复示例业务上下文，不破坏历史记录。
- 归档侧栏由固定“菌藻发酵研发线”改为通用“企业研发工作空间”。
- 完整演示检查增加产业和工艺类型存在性校验。

## 闭环价值

原始数据、模型、仿真与优化结果现在都能归属于同一业务上下文。下一阶段可以依据该上下文和设备适配包动态决定虚拟设备、参数表及约束条件，而不是把温度、pH、搅拌等培养参数作为所有行业的固定模板。

## 验证

- 新增测试先证明缺少业务上下文能力，再实现功能。
- 后端全量测试：343 passed，1 skipped。
- 前端类型检查和生产构建通过。
- 浏览器检查新建实验字段及示例实验总览，控制台无错误。
- 完整演示闭环检查通过。
