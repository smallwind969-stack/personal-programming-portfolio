# STEP107 参数绑定人工闸门

## 目标

让参数字典中的自定义变量进入可追溯的模型特征绑定流程，而不是停留在“未接入”提示。

## 本步完成

- 仿真页面继续沿用设备适配与特征绑定人工闸门。
- 绑定建议下拉选项会读取实验参数字典，除内置参数外也能显示企业自定义参数。
- 没有人工晋升模型时，页面列出本实验等待绑定的参数，并明确先完成数据分析和模型准入。
- 自定义参数完成绑定前，不会进入临时试算请求。
- 绑定建议、单位换算、操作人、确认理由和版本继续使用现有审计链保存。
- 示例仿真保持隔离，不能通过此入口伪造正式绑定或设备控制。

## 验证

- 前端 TypeScript 类型检查通过。
- 前端生产构建通过。
- 完整演示闭环检查通过。
- 浏览器检查企业仿真页面存在“设备适配与特征绑定”入口，控制台无错误。
