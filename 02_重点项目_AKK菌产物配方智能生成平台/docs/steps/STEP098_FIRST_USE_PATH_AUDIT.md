# STEP098：首次使用路径审计

## 三种入口

新建实验页面明确区分：

1. 企业实验：填写实验目标、产品、指标和批次，上传真实设备数据；
2. 隔离示例：没有数据时直接体验完整的分析、仿真和优化闭环；
3. 空白档案：先建立实验目标，稍后再补充文件资产。

## 关键边界

- 企业实验和空白档案不会自动运行模型；
- 示例数据有隔离提示，不会登记为真实测量、正式模型或设备控制依据；
- 首次上传后先生成字段、单位和转换证据，再进入人工确认；
- 没有文件时页面明确提示“尚未启动算法进程”，不会用虚构数据推进。

## 验证

- 示例实验、空白实验和企业工作区创建相关回归：`9 passed`；
- 示例实验全链路检查通过；
- 新建页面和实验工作区生产构建通过。
