# STEP109 自定义参数输入契约

## 目标

把已登记的自定义参数纳入仿真试算请求结构，为后续通用模型计算器提供稳定输入接口，同时明确当前规则计算器尚未使用这些参数的边界。

## 本步完成

- `SimulationPredictRequest` 新增受控 `customParameters` 数值字典。
- 自定义键必须符合 `custom_数字` 格式，值必须为有限数值，最多 50 项。
- 预测响应原样回显自定义参数，形成输入证据。
- 当前规则计算器在风险中明确提示：自定义参数已记录但尚未纳入评分。
- 试算快照沿用完整请求参数，因此后续通用模型可以读取同一份输入。
- 前端旧场景自动补空字典，保持历史仿真请求兼容。

## 安全边界

这个接口只接收数值参数，不接收设备控制命令。参数是否真正参与预测，必须经过实验白名单、特征绑定、单位换算和模型能力校验，不能因为字段进入请求就宣称模型已经支持。

- 前端类型检查与生产构建通过。
- 完整演示闭环检查通过。
