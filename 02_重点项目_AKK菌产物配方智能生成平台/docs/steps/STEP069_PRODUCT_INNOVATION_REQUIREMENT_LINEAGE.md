# Step069：产品创新需求血缘闭环

日期：2026-07-21

## 已实现

### 产品创新资产持久化

- 新增 `SqliteProductInnovationStore`。
- 持久化产品创新运行和人工确认需求版本。
- 支持命令幂等、来源运行唯一、需求版本递增和内容哈希。
- API 重启后可恢复智能体运行、确认状态和需求版本。

### 页面恢复与提示词引导

- 产品创新页根据实验目标与目标产物预填产品构想。
- 默认写入研发建议和禁止设备控制边界。
- 增加中文提示词写作指导。
- 已确认需求显示“已人工确认”和只读版本。
- 未确认运行刷新后通过 latest API 恢复。
- 已确认版本可直接进入工艺优化并重新开始演示。

### 需求驱动工艺优化

- 优化运行创建时冻结最新确认需求：
  - `productRequirementVersionId`
  - 版本号
  - 工作名称
  - 来源运行
  - 内容哈希
- 三套候选方案说明明确显示需求名称与需求版本。
- 验证指标加入需求目标指标。
- 风险清单加入产品需求风险。
- 新需求不会静默修改已存在的优化运行。

## 安全边界

- 产品创新输出仍是研发实验建议。
- 不生成最终配方比例。
- 不宣称未经验证的产品性能。
- 不下发设备控制指令。
- 不让新需求自动覆盖既有运行。
