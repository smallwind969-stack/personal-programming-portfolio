# STEP092：演示链路可重复检查

## 目标

把“归档 → 数据分析 → 仿真模拟 → 工艺优化”的演示验证从人工点击固化为可重复的运行检查。

## 新增检查

运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check-demo-flow.ps1
```

脚本依次检查：

1. API 健康状态；
2. 归档至少存在一条实验；
3. 指定实验总览 ID 和生命周期状态；
4. 数据分析进度清单和步骤数量；
5. 仿真运行已完成且存在正式结果快照；
6. 工艺优化运行已完成且存在结果摘要；
7. 实验工作区页面返回 HTTP 200。

## 实测结果

- 归档实验数：42；
- 示例实验：`exp-eebc4a9daa21`；
- 实验阶段：工艺优化；
- 数据分析：6 步，当前投影进度 88%；
- 仿真：`completed`，结果快照 `official-3a4e518d7d`；
- 优化：`completed`；
- 工作区：HTTP 200。

这说明演示页面不是孤立静态展示，而是能从同一条实验记录读取三阶段运行结果。
