# Step054：模型评估与可靠性智能体

日期：2026-07-21

## 本步骤目标

在“数学模型已晋升”和“允许进入仿真”之间增加独立、持久化、可人工签署的可靠性评估层。仿真不得只依据单个 R² 或实验总览中的静态置信度开放。

## 已完成

- 新增持久化 `ModelEvaluationAgent`。
- 只评估人工晋升且模型卡血缘完整的真实模型。
- 验证：
  - 模型版本；
  - 研究活动与候选试验；
  - 数据集和特征集指纹；
  - 模型产物 SHA-256；
  - 模型卡与注册表血缘一致性。
- 真实训练模型卡新增：
  - 留出集实际值、预测值和残差；
  - 残差均值、标准差、最大绝对残差；
  - 一阶残差自相关；
  - 预测值与残差相关性；
  - 训练段和留出段特征统计；
  - 留出数据处于训练范围内的覆盖率；
  - 标准化特征效应或树模型重要性；
  - 目标变量训练范围。
- 生成经验 95% 预测区间：
  - 使用留出集绝对残差的 95% 分位数；
  - 保存样本量和经验覆盖率；
  - 明确标注未使用独立校准集，不能宣称统计校准完成。
- 计算逐特征漂移：
  - 训练/留出均值；
  - 标准化均值漂移；
  - 训练范围覆盖；
  - 低、中、高风险等级。
- 计算六维可靠性评分：
  - 预测性能；
  - 交叉验证稳定性；
  - 分布稳定性；
  - 训练范围覆盖；
  - 残差偏差；
  - 样本充分度。
- 自动仿真准入条件包括：
  - 产物哈希通过；
  - 留出集 R² 不低于 0.5；
  - 交叉验证 R² 标准差不高于 0.25；
  - 最大标准化均值漂移不高于 2.5；
  - 平均训练范围覆盖率不低于 80%；
  - 残差一阶自相关绝对值不高于 0.8；
  - 训练行不少于 20、留出行不少于 5；
  - 综合可靠性评分不低于 0.7。
- 自动检查通过后仍必须由研发人员填写依据并确认。
- 自动检查未通过时，“确认并开放仿真”后端和前端同时禁止。
- 报告绑定当前晋升模型；模型版本变化后旧报告自动判定为过期。
- 人工确认后同步更新实验总览：
  - 当前模型版本；
  - 模型类型；
  - 可靠性评分；
  - 结果版本；
  - 数据分析完成状态；
  - 仿真入口和运行权限。
- 仿真后端准入已改为读取最新人工确认的可靠性报告，不再依赖旧静态置信度。

## 通用产线适配修复

真实验收发现旧仿真编排器只支持四个写死的实验 ID。现已新增：

- 内置行业模板仍可复用；
- 任意新建企业实验自动使用 `generic-enterprise-process`；
- 通用模板包含七个环节：
  - 模型可靠性校验；
  - 仿真系统初始化；
  - 原料与培养基准备；
  - 核心生产过程；
  - 下游处理；
  - 产物收集；
  - 结果评估。
- 新实验自动生成通用虚拟仪器参数；
- 仿真仪表盘从可靠性报告读取真实 R²、MAE 和可靠性评分。

该修复使平台从“只能演示预置 AKK 实验”进一步转向“任意企业实验都能进入通用工作流”。
