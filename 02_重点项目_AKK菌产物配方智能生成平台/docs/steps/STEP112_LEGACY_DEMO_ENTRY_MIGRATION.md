# STEP112 旧演示入口迁移

## 目标

避免旧版 AKK 专属商品配方页面与新的通用实验工作区并存，造成入口混乱和平台能力边界误解。

## 本步完成

- `/demo` 改为隔离示例引导页，不再渲染旧版 AKK 专属配方工作台。
- 引导页提供实验归档、新建实验和企业规律三个业务入口。
- 明确示例模式的边界：不代表真实测量、正式模型准入或设备控制。
- 新旧入口统一回到“实验归档 → 新建实验 → 数据分析 → 仿真模拟 → 工艺优化 → 报告”的主流程。
- 页面不主动暴露底层智能体或模型编排术语。

## 验证

- 前端类型检查通过。
- 前端生产构建通过。
- 完整演示闭环通过。
- 浏览器实测 `/demo` 能看到实验归档入口，旧 AKK 专属标题已移除，控制台无错误。
