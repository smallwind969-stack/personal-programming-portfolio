## 内置智能体

数据分析监督、数据收集定位、字段识别、清洗对齐、特征工程、数学建模、模型评估、结果解释、人工确认、产品创新、仿真模拟、工艺优化。

## 架构依据

LangGraph 自定义工作流适合把确定性逻辑与智能体行为组合；子图作为父图节点能够获得稳定命名空间和可检查状态。当前系统因此保留确定性路由、检查点和人工门禁，不让 LLM 自由改变研发流程。

## 研发边界

目录没有真实产线控制智能体；所有清单都声明“仅输出研发实验建议、不得直接控制真实产线、关键结论保留人工确认”。
