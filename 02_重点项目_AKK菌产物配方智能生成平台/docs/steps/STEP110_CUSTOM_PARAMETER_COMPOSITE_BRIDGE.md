# STEP110 自定义参数组合预测桥接

## 目标

确保自定义参数从仿真页面进入已晋升模型组合预测时，不因前端请求结构而丢失。

## 本步完成

- 仿真运行页面调用组合预测前，将 `customParameters` 平铺到模型输入字典。
- 原始试算请求仍保留嵌套字典，便于报告和快照复现。
- 绑定服务继续依据正式绑定版本读取对应自定义键，并输出单位换算审计。
- 未完成绑定的自定义键不会被组合预测自动使用。

## 闭环边界

参数进入组合预测请求不等于模型已经支持。只有模型版本、绑定版本、实验参数白名单和输入值均通过校验，才会形成预测目标；否则返回不可用原因，不生成伪结果。

- 前端 TypeScript 类型检查和生产构建通过。
- 组合预测与绑定测试：9 passed。
- 完整演示闭环检查通过。
