# STEP096：实验工作区入口审计

## 目标

用户从实验归档进入单条实验后，应能找到完整的研发工作区，而不是只能看到一张结果卡片。

## 已确认入口

- 实验总览：生命周期、阶段状态、模型依据、风险与验证项；
- 流程进程：运行节点、后台命令、人工控制和审计记录；
- 产品需求研判：把产品构想固化为待验证需求版本；
- 数据分析：数据接入、映射确认、清洗对齐、快照、特征和建模评估；
- 仿真模拟：模型血缘、产线参数、阶段进度和预测结果；
- 工艺优化：三套方案、文本参数修改、训练过程、人工验收和版本回写；
- 实验报告：基于证据的结果解释和研发建议。

## 自动检查

演示链路脚本现在会对同一实验逐一请求：

`/agents`、`/innovation`、`/analysis`、`/simulation`、`/optimization`、`/reports`

所有工作区路由均返回 HTTP 200，前端生产构建通过。

## 业务边界

入口展示的是研发流程和证据，不主动把内部实现术语作为产品标题；产品需求、仿真和优化结果仍需人工判断，不连接真实设备。
