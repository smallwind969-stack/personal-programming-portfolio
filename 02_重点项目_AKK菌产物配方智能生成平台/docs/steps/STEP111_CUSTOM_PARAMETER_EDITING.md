# STEP111 已校准自定义参数编辑

## 目标

让实验参数字典中的已校准自定义参数在仿真页面可直接编辑，同时保持未校准参数只读和结果边界透明。

## 本步完成

- 参数定义同时具备单位、上下界和默认值时，仿真页面显示“已校准自定义参数”输入区。
- 编辑值写入 `customParameters`，随临时试算快照保存。
- 自定义输入沿用必填、数值和试算快照规则，不覆盖正式仿真参数。
- 缺少边界或默认值的参数仍显示“待校准或未接入”，不可编辑。
- 结果区明确提示自定义值是否真正参与当前模型计算。
- 示例“溶氧”统一使用 `custom_1` 受控键，历史示例读取时也自动恢复为可编辑定义。

## 验证

- 后端全量测试：347 passed，1 skipped。
- 前端类型检查和生产构建通过。
- 完整演示闭环通过。
