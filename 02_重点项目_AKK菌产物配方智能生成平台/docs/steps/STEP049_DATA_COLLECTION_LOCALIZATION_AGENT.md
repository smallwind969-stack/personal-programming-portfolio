# Step049：数据收集定位智能体与人工确认门禁

日期：2026-07-20

## 架构纠正

本步严格采用多智能体分层：

- `DataCollectionLocalizationAgent`：业务编排智能体；
- `ExperimentFileService`：底层文件解析、清洗、对齐和快照工具；
- `DeviceAdapterPackService`：设备适配包读取与完整性验证工具；
- `ExperimentService`：实验状态和归档持久化工具。

文件解析服务不再被当作数据智能体。

## 已完成功能

- 上传单个 CSV/TXT 后自动启动数据收集定位智能体。
- 批量上传后为每个文件生成独立接入运行。
- 自动读取实验锁定的设备适配包。
- 再次验证适配包版本、包 ID 和 SHA-256 内容指纹。
- 对每个原始字段输出：
  - 是否命中设备别名；
  - 标准字段；
  - 对应仿真参数；
  - 原单位与目标单位；
  - 比例和偏移；
  - `y = x × scale + offset` 换算公式；
  - 可审计证据；
  - 是否需要人工确认。
- 未命中字段不被静默丢弃，必须人工填写标准字段。
- 前端新增逐字段复核表，可修改标准字段与目标单位。
- 人工确认前：
  - 接入运行状态为 `needsReview`；
  - 实验状态为“字段与单位待确认”；
  - 数据集快照接口返回 `409`；
  - 数据分析智能体保持等待。
- 全部字段确认后：
  - 接入运行状态为 `confirmed`；
  - 实验状态变为“数据分析中”；
  - 数据分析阶段 `canRun=true`；
  - 可生成带 hash 的建模数据集快照；
  - 数据分析多智能体状态图开放。
- 刷新页面后可恢复当前进程视图。
- 保留旧演示实验的兼容路径。
