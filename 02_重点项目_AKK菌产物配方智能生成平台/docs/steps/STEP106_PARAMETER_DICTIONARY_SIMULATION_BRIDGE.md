# STEP106 参数字典接入仿真工作台

## 目标

让仿真页面读取实验参数字典，区分“已绑定且可试算”的参数与“尚未接入当前计算模型”的参数，避免跨行业参数被静默忽略或伪造预测。

## 本步完成

- 仿真工作台接收实验业务上下文和参数字典。
- 已知参数的显示名称、单位和边界优先读取实验定义，页面不再只依赖固定标签。
- 自定义参数单独显示为“未接入当前计算模型”，同时展示单位、边界或待校准状态。
- 未绑定参数不会进入临时试算请求，必须完成特征绑定和范围校准后才开放。
- 保留当前仿真请求契约，菌藻示例的既有结果和试算能力不受影响。

## 当前边界

本步完成参数资产到仿真界面的安全桥接；真正把自定义参数转换为模型输入，需要下一阶段完成特征绑定映射、单位换算和后端计算器的通用参数接口。系统通过明确的“未接入”状态避免产生虚假闭环。

## 验证

- 仿真相关后端测试：33 passed。
- 前端 TypeScript 类型检查与生产构建通过。
- 完整演示闭环检查通过。
- 浏览器实测仿真页显示“溶氧 · 待校准”，控制台无错误。
