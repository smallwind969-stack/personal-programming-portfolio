# Step062：实验闭环总览与跨阶段入口

## 本步目标

让实验归档和实验详情页直接展示完整研发闭环，解决功能入口分散、用户不知道当前应该进入哪个智能体的问题。

统一闭环：

`数据分析 → 模型评估 → 补实验设计 → 实验执行 → 真实测量 → 反馈重训练`

## 已实现

1. 新增只读 `ExperimentLifecycleProjectionService`，从现有权威对象计算闭环状态，不复制业务状态、不推进任务。
2. 每个阶段展示状态、进度、中文摘要、等待原因、证据版本、数量统计、入口和下一操作。
3. 投影严格使用当前模型、报告和补实验计划血缘，历史重训练不能填充当前计划的重训练节点。
4. 补实验执行按已批准候选覆盖率计算；多个候选只完成一部分时显示实际比例，而不是误报完成。
5. 真实测量只统计当前计划执行批次的交接任务和反馈资产。
6. 当下游模型评估已经存在时，该证据会覆盖工作区遗留的早期“数据分析待确认”标记，避免当前位置倒退。
7. 可靠性已准入时，补实验设计、执行、测量和反馈重训练显示“本轮不需要”。
8. 实验详情页新增六节点“多智能体研发闭环”导航，可直接进入对应工作区并展开证据版本。
9. 首页实验归档新增“闭环位置”、进度条和下一动作，不再只显示笼统三阶段名称。
10. 新增归档批量摘要接口，避免首页逐条发起生命周期请求。

- `GET /experiments/{id}/lifecycle`
- `GET /experiments/lifecycle-summaries`
