# Step053：数学建模智能体与真实模型卡

日期：2026-07-21

## 本步骤目标

将现有单一算法、一次切分的研究演示升级为可审计的真实数学建模工作流，同时继续清晰区分 `mock_evaluation` 与 `real_runner`，不以演示指标冒充真实训练。

## 已完成

- sklearn 执行器升级为 `sklearn-time-series-modeling-v2`。
- 支持三类候选算法：
  - Ridge；
  - Random Forest；
  - Gradient Boosting。
- 所有随机模型固定 `random_state=42`。
- 时序数据全程禁止随机打乱。
- 最后 20% 时间段作为独立留出集。
- 前 80% 训练段内部执行扩展窗口 `TimeSeriesSplit`。
- 每个真实候选保存：
  - 每折训练和验证索引范围；
  - 每折 MAE、RMSE、R²；
  - 交叉验证均值与标准差；
  - 留出集 MAE、RMSE、R²；
  - 训练行、留出行与交叉验证折数。
- 新增完整模型卡：
  - 算法、模型类型与超参数；
  - 随机种子；
  - 数据快照和特征集指纹；
  - 特征、目标和特征范围；
  - 时间切分策略；
  - Python 与 sklearn 版本；
  - 已知限制和适用边界。
- 模型卡同时保存到研究试验记录和内容寻址模型产物元数据。
- 自动候选现在按有边界的单变量策略比较算法和超参数。
- 未知参数不再静默忽略，后端直接拒绝。
- 新增不可由用户降低的真实模型硬门禁：
  - 留出集 R² 必须为正；
  - 必须存在模型卡；
  - 必须使用时间顺序留出协议；
  - 留出集至少 3 行。
- 用户配置的 R²、MAE 和最小提升门槛仍需同时通过。
- 只有当前最佳候选可以晋升。
- 人工晋升必须填写操作人与判断依据。
- 晋升后写入模型注册表，保存模型、数据、特征、指标和审批血缘。
- 重建中文“数学建模智能体”工作台，移除原有乱码：
  - 显示真实训练或演示评测；
  - 显示候选算法、假设、指标和结论；
  - 支持自动候选；
  - 支持人工选择算法和编辑超参数；
  - 展开查看模型卡；
  - 显示后台任务状态；
  - 显示人工签署和晋升版本。
