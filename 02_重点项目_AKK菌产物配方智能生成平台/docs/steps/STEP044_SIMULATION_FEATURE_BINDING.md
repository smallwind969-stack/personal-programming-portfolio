# STEP044 完成记录：仿真特征绑定与多目标模型组合

日期：2026-07-20

## 已实现

1. 新增版本化特征绑定合同，将标准字段、仿真参数和模型特征连接起来。
2. 每条绑定记录源单位、目标单位、比例、偏移量、确认人、确认原因和创建时间。
3. 绑定必须完整且唯一覆盖模型特征；未知仿真参数、重复特征、非有限换算和缺失输入全部拒绝。
4. SQLite 持久化绑定版本；同一版本幂等，但禁止被不同绑定血缘覆盖。
5. 模型注册表支持按目标字段选择最新人工批准模型。
6. 新增多目标组合推理服务，每个目标独立绑定模型版本、trial、数据快照和产物摘要。
7. 使用验证 RMSE 输出 `prediction ± 1.96 × RMSE`，明确标记为未经校准的近似 95% 区间。
8. 缺少批准模型或确认绑定的目标进入 `unavailableTargets`，不使用规则结果冒充真实模型预测。
9. 新增绑定确认 API：`POST /simulation/experiments/{experimentId}/model-bindings`。
10. 新增组合预测 API：`POST /simulation/experiments/{experimentId}/composite-predict`。
11. 仿真页面新增“已晋升模型仪表盘”，显示真实预测、近似区间、可靠性、模型版本和不可用指标。

## 安全与解释边界

- 特征绑定只有人工确认版本可以使用。
- 默认拒绝模型训练范围外输入；允许外推时必须显式开启并留下标记。
- `approximate95_rmse` 不是校准置信区间，不用于宣称统计覆盖率。
- 所有输出仍是“研发实验建议”，不能直接形成生产设备控制指令。
