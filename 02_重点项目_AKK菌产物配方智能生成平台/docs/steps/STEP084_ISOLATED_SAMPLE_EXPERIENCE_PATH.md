# Step 084：隔离示例体验通道

## 目标

第一次没有真实实验数据时，用户仍可以体验完整平台流程；示例流程必须和正式实验使用相同的阶段编排，但所有产物都限制在隔离范围内。

## 当前入口

在“新建实验”中选择“使用行业示例数据”，系统创建菌藻培养示例、写入示例 CSV、生成数据接入转换证据，并进入数据分析页面。

## 后续体验链路

1. 复核示例字段与单位转换证据。
2. 创建并运行隔离建模轮次。
3. 由用户点击“人工确认进入演示仿真”。
4. 在仿真工作区调整文本参数并观察预测结果和过程状态。
5. 进入演示工艺优化，选择候选方案并提交人工复核。

## 隔离约束

- 示例模型不会写入企业正式模型注册表。
- 示例结果不会登记为真实测量或企业规律。
- 示例优化只生成演示版本，不下发设备控制指令。
- 页面明确展示“示例实验 · 隔离模型通道”和使用限制。

## 运行态验证

已通过 `POST /experiments/sample-workspaces` 创建示例工作区，返回示例来源、模板版本、接入运行 ID 和三阶段准入状态；初始状态正确停留在“数据分析 / 字段与单位待确认”，没有伪造模型结果直接开放仿真。
