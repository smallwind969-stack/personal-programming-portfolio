# Step063：人工待办中心与闭环筛选

## 本步目标

把分散在模型复核、补充实验、真实测量和反馈重训练工作台中的人工门禁集中投影到实验归档首页，让研发负责人能先看到“现在需要我处理什么”，再进入对应实验完成操作。

## 已实现

1. 新增只读 `HumanActionCenterService`，根据当前实验、当前模型报告和当前补充实验计划的血缘关系生成待办，不复制业务状态，也不自动执行操作。
2. 支持十类人工动作：可靠性复核、生成/复核补充实验方案、建立/继续执行批次、建立测量任务、录入/复核真实测量、建立/复核反馈重训练。
3. 每项待办包含稳定 ID、实验、闭环节点、优先级、操作标题、说明、目标路由、证据引用和阻塞原因。
4. 历史模型或历史重训练结果不会冒充当前计划的待办；待办仅采用当前血缘证据。
5. 新增批量接口 `GET /experiments/human-actions`，一次返回总量、高优先级数量、涉及实验数、按实验汇总和排序后的待办列表。
6. 首页新增“我的待处理”，优先展示前六项待办，并可直接跳转到对应工作台。
7. 实验列表新增“闭环位置”筛选和“只看有人工待办”筛选；每条实验状态旁显示待办数量。
8. 修复归档页增量修改造成的中文字符编码损坏，重新构建为正确中文源文件。

## 安全边界

- 本中心只是待办投影，不会自动签署、批准、录入测量、提升模型或控制设备。
- 所有会改变研发证据的动作仍需进入对应工作台，由人工明确提交。
- 待办的来源和去向均保留证据引用与路由，便于审计和追溯。
