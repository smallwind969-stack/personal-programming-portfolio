## 安全边界

- LLM 不执行数据清洗、单位换算和数学评估。
- LLM 不晋升模型、参数或实验结果版本。
- LLM 不生成或下发真实设备控制指令。
- LLM 失败不伪装为成功，页面显示明确失败分类。
