# STEP065 数据分析六步推进清单

## 目标

让首次进入实验的数据分析页面具备明确入口、当前进度、阻塞原因、可审计证据和下一步动作，避免用户面对多个智能体工作台时不知道从哪里开始。

## 已实现

- 新增只读进度投影接口：`GET /experiments/{experiment_id}/analysis-progress`。
- 固定展示六个研发环节：数据接入、字段确认、清洗对齐、数据集快照、特征工程、建模评估。
- 每一步返回状态、摘要、证据引用、阻塞原因、页面锚点和动作名称。
- 页面顶部新增“数据分析智能体 · 六步闭环”进度面板。
- 进度面板支持刷新和跳转到对应工作台。
- 人工确认字段与单位后调用 `router.refresh()`，立即切换到清洗对齐工作台。
- 进度是现有实验血缘的只读投影，不会替用户自动确认、自动晋升模型或自动控制设备。

## 演示验证

- 示例实验：`exp-2a8d3e46a85f`
- 确认前：25%，当前第 2 步“字段和单位人工确认”。
- 浏览器人工确认 6 个字段后：38%，当前第 3 步“数据清洗与时间轴对齐”。
- 页面已显示“开始清洗对齐”按钮，后续快照、特征和建模步骤保持上游门禁。
