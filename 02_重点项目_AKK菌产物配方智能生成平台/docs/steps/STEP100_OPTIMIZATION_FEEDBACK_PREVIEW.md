# STEP100：工艺优化后续闭环预览

## 问题

示例模式原先为了避免误用，完全隐藏了现实验证、反馈数据集和重训练入口，用户看不到优化之后如何回到实验数据库。

## 处理

示例优化页现在增加只读的“后续闭环预览”：

1. 现实验证批次：等待企业真实实验回传；
2. 反馈数据集：经过质量检查和人工确认后形成训练资产；
3. 权重更新与复评：至少三批合格反馈，在留出集上重新评估后才开放。

预览不创建伪造批次、不写入虚构反馈、不生成重训练结果；正式企业实验仍使用真实数据闭环组件。

## 验证

- 前端构建通过；
- 示例优化路由 HTTP 200；
- 演示血缘检查通过；
- 既有优化相关后端测试保持通过。
