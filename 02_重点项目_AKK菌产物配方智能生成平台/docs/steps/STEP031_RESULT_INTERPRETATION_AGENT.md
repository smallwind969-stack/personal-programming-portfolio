# Step031：实验结果解释智能体

日期：2026-07-20

## 目标

把已验证训练指标、风险和人工复核项转化为结构化实验结果解释与下一轮研发建议，同时确保语言模型不能改写指标、版本、仿真准入状态或生产控制参数。

## 已实现

- 新增供应商无关的结果解释提供器协议和严格 JSON 契约。
- 支持 Ollama 与 OpenAI-compatible 本地模型；请求包含明确 JSON Schema、证据白名单和有界上下文。
- 上下文只包含任务 ID、目标字段、状态、置信等级、MAE、RMSE、R²、已有风险、建议和人工复核项。
- 模型输出不包含指标值；前端显示的数值始终来自权威训练结果。
- 每条指标解释、模式、风险解释和实验建议必须引用输入证据 ID。
- 所有权威指标必须完整解释，所有已有风险必须完整覆盖，禁止选择性省略。
- 禁止真实产线控制、仿真批准、模型晋升、上市承诺和疾病治疗声明。
- 本地模型禁用、超时、不可达、非法响应或策略拒绝时生成确定性解释并显示脱敏回退原因。
- 新增不可变解释运行快照、同命令并发去重和跨实验并行执行。
- 新增 API：
  - `POST /experiments/{experimentId}/result-interpretation-runs`
  - `GET /experiments/{experimentId}/result-interpretation-runs/{runId}`
- 解释能力已绑定统一数据分析工作流的 `model-evaluation` 节点；运行时只保存解释快照引用和摘要。
- 前端模型评估节点完成后显示权威指标、证据化解释、风险、下一轮研发实验建议、未解决问题和回退状态。
- 新增 `RESULT_INTERPRETATION_LLM_ENABLED=false` 显式安全开关。

## 边界

- 输出只属于研发实验建议。
- 不替代数学模型、统计检验、人工评审或现实实验。
- 不生成完整论文，不决定仿真准入，不控制真实设备。
