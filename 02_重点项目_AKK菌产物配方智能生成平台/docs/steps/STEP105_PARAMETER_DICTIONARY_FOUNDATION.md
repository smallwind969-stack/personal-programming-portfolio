# STEP105 参数字典基础

## 目标

为后续跨行业仿真和工艺优化准备实验级参数字典，避免把培养场景中的少数变量误当成所有产线的固定参数。

## 本步完成

- 在实验业务上下文中新增参数定义：键名、显示名称、单位、上下界、默认值和来源。
- 新建实验根据关键工艺参数自动生成基础参数定义；已知温度、pH、搅拌、培养时长和压力会补充示例边界，其他参数保留待校准状态。
- 菌藻示例显式登记温度、pH、溶氧、搅拌速度和培养时长参数字典。
- 实验总览增加参数字典预览，显示边界是否已校准。
- 保持原有仿真请求契约兼容；本步先完成参数资产和谱系，不把未知行业参数伪装成可计算结果。

## 下一步承接

后续仿真工作台将读取该字典，按参数来源和边界动态生成可编辑控件；只有已经绑定模型特征并通过范围校验的参数，才允许进入仿真试算和工艺优化。
