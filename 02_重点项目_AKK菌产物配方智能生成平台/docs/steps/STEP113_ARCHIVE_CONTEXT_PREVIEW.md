# STEP113 归档业务上下文预览

## 目标

让实验归档在不进入详情页的情况下，就能区分不同产业、工艺和产线实验，强化归档作为平台主入口的定位。

## 本步完成

- 归档条目新增产业和工艺类型字段。
- 新建实验保存的业务上下文会同步出现在归档预览。
- 历史档案缺少上下文时显示“未配置”，不阻断旧数据读取。
- 表头改为“实验名称 / 业务上下文”，用户可先按产业和工艺识别实验，再查看状态、结果和置信度。
- 全局主导航保持实验归档、运行记录、人工操作、模型资产、企业规律和系统设置，不再暴露旧版配方入口。

## 验证

- 后端归档与 API 测试：36 passed。
- 前端类型检查与生产构建通过。
- 完整演示闭环通过。
- 浏览器实测归档显示业务上下文，控制台无错误。
