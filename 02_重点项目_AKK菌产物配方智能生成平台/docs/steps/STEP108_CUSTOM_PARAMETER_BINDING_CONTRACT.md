# STEP108 自定义参数绑定契约

## 目标

让实验参数字典签发的自定义参数可以进入正式特征绑定，同时继续拒绝未登记的任意控制键。

## 本步完成

- 正式绑定契约保留内置仿真参数白名单。
- 新增受控的 `custom_数字` 参数键格式，仅由实验参数字典生成。
- 绑定接口读取实验参数字典并校验自定义键是否属于当前实验。
- 不存在实验上下文时，历史内置参数绑定仍保持兼容；自定义键会被拒绝。
- 设备适配包和绑定建议生成器共享同一受控键校验。
- 自定义参数绑定结果继续生成单位换算审计和绑定版本，可被后续模型输入服务读取。
- 任意类似 `startMotor` 的未登记控制键仍会被拒绝，避免把参数绑定误用为设备控制接口。
