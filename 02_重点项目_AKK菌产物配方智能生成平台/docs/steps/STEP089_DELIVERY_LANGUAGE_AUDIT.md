# Step 089：交付文案与启动脚本审计

## 已验证

- 本地、局域网和健康检查脚本语法通过。
- 健康检查脚本使用稳定的 ASCII 终端输出，避免 Windows PowerShell 编码差异造成乱码。
- 启动脚本使用统一的 3000/8000 入口。
- 研究任务、模型资产、任务队列和实验数据路径已明确分层，重启后不会因旧 Worker 或空数据库造成状态错乱。
- 主要业务页面使用实验归档、数据分析、仿真模拟、工艺优化、企业知识库、增强推理等业务语言。
- 后端全量测试和前端生产构建均通过。

## 语言边界

内部运行详情页仍保留必要的运行编排信息，供研发工程师查看算法过程；归档首页、新建实验、数据分析、仿真和工艺优化主入口不以技术实现名词作为操作入口。
