# Step052：版本化特征工程智能体

日期：2026-07-20

## 本步骤目标

将“特征工程”从多智能体流程中的演示节点升级为真实、持久化、可审计的专业智能体。建模不能再自动把第一个字段当作目标变量，也不能绕过人工确认直接消费临时数据。

## 已完成

- 新增持久化 `FeatureEngineeringAgent`。
- 只允许消费带清洗血缘的建模数据集快照。
- 目标变量必须由研发人员选择。
- 输入字段必须由研发人员选择，目标字段不得同时作为输入特征。
- 支持真实生成：
  - 原始值特征；
  - 正向历史滞后特征；
  - 一阶变化量；
  - 仅使用当前及历史数据的滚动均值；
  - 仅使用当前及历史数据的滚动标准差。
- 每个特征保存：
  - 名称与类型；
  - 来源字段；
  - 完整数学公式；
  - 滞后或窗口参数；
  - 有效行数；
  - 缺失率。
- 新增泄漏与质量审计：
  - 目标字段直接作为输入时拒绝运行；
  - 非正向滞后即未来信息被契约拒绝；
  - 无效窗口被契约拒绝；
  - 全缺失特征为阻断问题；
  - 常量特征给出风险提示；
  - 时间顺序不一致时排序并记录提示。
- 每次运行保存：
  - `featureSetId` 与递增版本；
  - 快照、清洗运行和清洗输出哈希；
  - 输入指纹与输出哈希；
  - 特征矩阵；
  - 泄漏审计；
  - 人工确认记录。
- 只有人工确认后的特征集可以进入建模。
- 新版本确认后，旧确认版本转为 `superseded`，仍保留完整记录。
- 数据快照发生变化后，旧特征集被实时判定为过期并禁止训练。
- sklearn 真实训练器已经改为读取确认后的特征集矩阵，不再调用旧的自动字段选择导出器。
- 对持久化实验创建研究活动时增加后端特征集门禁。
- 新增中文特征工程工作台：
  - 选择预测目标；
  - 选择基础输入字段；
  - 设置滞后和滚动窗口；
  - 查看真实公式、有效行与缺失率；
  - 查看泄漏审计；
  - 勾选最终启用特征；
  - 填写确认依据并人工放行；
  - 展示版本、快照、输入指纹和输出哈希。
- 特征集未确认时，前端建模实验中心保持锁定。
