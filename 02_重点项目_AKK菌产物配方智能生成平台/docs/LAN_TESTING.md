# 局域网测试发布说明

本方式适合内部小组体验，不需要部署到公网服务器。你的电脑作为临时测试服务器，组员手机或电脑需要连接同一个 Wi-Fi。

## 启动方式

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-lan.ps1
```

脚本会自动完成：

- 获取当前电脑的局域网 IP
- 更新 `apps/web/.env.local`
- 启动 FastAPI 后端到 `0.0.0.0:8000`
- 启动 Next.js 前端到 `0.0.0.0:3000`
- 输出可分享访问地址

## 当前测试地址

当前电脑检测到的局域网地址为：

```text
http://10.208.171.65:3000
```

组员访问前需要确认：

- 手机或电脑与这台电脑在同一个 Wi-Fi 下
- 你的电脑不能休眠
- Windows 防火墙允许端口 `3000` 和 `8000`

## 体验路径

1. 打开首页，进入商品设计台。
2. 输入目标商品类型，例如“牛奶”“低糖酸奶”“儿童软糖”“银发营养粉”。
3. 点击“智能推荐配方”，查看 AKK 原料比例是否实时变化。
4. 点击“生成商品方案”，进入方案建议书。
5. 在“商品方案库”查看历史方案。
6. 在“实验平台”查看自动生成的工业打样模拟数据。

## 常见问题

如果组员打不开页面：

- 先在你的电脑打开 `http://localhost:3000`，确认本机可访问。
- 再打开 `http://10.208.171.65:8000/health`，确认 API 返回 `{"status":"ok"}`。
- 如果本机正常但组员打不开，通常是 Windows 防火墙拦截端口。
- 如果换了 Wi-Fi，局域网 IP 会变化，需要重新运行 `scripts/start-lan.ps1`。
