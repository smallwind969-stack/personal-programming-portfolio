# STEP120：通用实验文件接入

## 已实现

- CSV/TXT/TSV 继续按文本表格解析；
- XLSX 通过 Base64 上传，服务端只读读取第一个有效工作表；
- XLS、RAW、DAT、BIN 和未知二进制文件保留原始字节与 SHA-256，状态为 `awaiting_adapter`；
- 原件不会发送给模型，也不会被伪装成空表；设备适配器生成结构化派生资产后，才进入字段识别；
- `awaiting_adapter` 文件不会创建字段识别运行，也不会推进数据分析阶段；
- 前端上传控件已开放上述扩展名，并对待适配状态给出中文提示；
- 内容寻址存储支持二进制完整性校验。
