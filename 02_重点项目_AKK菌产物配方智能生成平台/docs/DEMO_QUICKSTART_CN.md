# 菌藻启元｜智能产线控制终端

## 本地启动

在项目根目录执行：

```powershell
.\scripts\start-local.ps1
```

工作台地址：<http://127.0.0.1:3000/>

启动后检查：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check-local.ps1
```

检查会确认接口健康状态、模型资产数量和工作台页面是否可访问。

## 第一次没有实验数据

1. 从“实验归档”进入“新建实验”。
2. 选择“使用行业示例数据”。
3. 在“数据分析”中复核字段、单位和时间轴。
4. 创建数据集快照和特征工程结果。
5. 运行建模评测并人工确认隔离模型准入。
6. 进入“仿真模拟”，观察七个仿真环节的状态变化。
7. 进入“工艺优化”，比较三套方案，选择参数并提交人工复核。

示例体验地址（服务启动后）：

<http://127.0.0.1:3000/experiments/exp-eebc4a9daa21>

## 有真实数据时

1. 选择“上传企业实验数据”。
2. 上传 CSV、TXT、Excel 或解密后的设备文本数据。
3. 逐项确认字段、单位和换算公式。
4. 检查清洗、时间轴对齐、异常点和特征工程证据。
5. 由研发人员确认模型评估和仿真准入。
6. 完成仿真后再开放工艺优化。

## 页面中的闭环

每个阶段都应能看到：输入、处理进度、计算依据、证据版本、人工确认点和下一步动作。

## 边界

示例结果只用于产品演示和研发流程教学，不得作为真实测量、企业正式模型或设备控制指令。正式实验同样只输出研发实验建议，必须经过现实实验验证后才能进入生产决策流程。
