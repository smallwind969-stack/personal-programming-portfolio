# STEP123：实验文件资产人工操作入口

## 交付内容

- 实验总览工作区新增“最近上传文件资产”区域，不再需要进入遗留数据页才能查看数据文件；
- 每个资产展示格式、行数、字段、内容指纹、解析状态和来源链路；
- 结构化派生文件显示对应原始设备文件，原始二进制文件标记为“原始证据，待转换”；
- 研发人员可从界面发起“移除”操作，必须填写原因并二次确认；
- 移除成功后，操作原因保留在审计记录中；若原始文件仍被派生数据引用，服务端返回冲突提示并阻止删除。

## 运行时修正

本地启动脚本以生产模式运行 Next.js。因此前端变更需要先执行生产构建，再启动服务；已重新构建并重启，避免浏览器展示旧构建产物。
