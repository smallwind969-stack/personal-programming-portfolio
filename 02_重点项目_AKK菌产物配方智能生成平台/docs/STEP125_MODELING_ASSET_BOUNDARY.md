# STEP125：建模数据与来源证据分层

## 问题

原始设备文件需要长期保留以支持审计，但它们尚未解析为字段和记录，不能被统计为建模输入，也不应参与清洗、字段识别或特征工程。

## 交付内容

- 只有状态为 `parsed` 的文件可进入字段识别、清洗、时间对齐、特征工程和数据集快照；
- 原始设备文件仍保留为来源证据，只有在被结构化派生文件引用时写入快照血缘；
- 数据集快照新增：
  - `assetCount`：真正进入建模的数据文件数；
  - `evidenceAssetCount`：随快照固定的原始来源证据数；
  - `analysisAssetIds` 与 `sourceEvidenceAssetIds`：完整的可追溯资产编号；
- 快照内容指纹同时绑定建模资产和来源证据的内容哈希；
- 工作台快照卡片以“建模文件 / 来源证据”分别展示，避免把设备原件误解为模型输入。
