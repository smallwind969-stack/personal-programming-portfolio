# STEP121：原始设备文件到结构化数据的血缘闭环

## 交付内容

- 原始设备文件（`RAW`、`DAT`、`BIN`、`XLS` 或未知二进制格式）以原始字节和 SHA-256 保存，状态为 `awaiting_adapter`；
- 用户可在上传 CSV、TXT、TSV 或 XLSX 时选择一个原始文件作为转换来源；
- 结构化派生资产保存 `derivedFromAssetId`，从而可追溯到对应的设备原始文件；
- 服务端只允许关联**同一实验**内、且仍处于 `awaiting_adapter` 状态的原始资产；跨实验或不符合状态的关联返回 HTTP 422；
- 已解析的派生资产才会触发字段定位和数据分析流程。原始文件不会被虚构为表格，也不会提前进入建模。

## 使用路径

1. 在实验的“数据接入”上传设备导出的原始文件；
2. 系统保存文件指纹，并提示需要设备适配或结构化转换；
3. 取得转换后的 CSV/XLSX 后再次上传，在“转换来源”选择对应的原始文件；
4. 系统开始字段识别、时间对齐、建模与后续仿真流程；
5. 在文件资产记录中可通过 `derivedFromAssetId` 审计数据来源。
