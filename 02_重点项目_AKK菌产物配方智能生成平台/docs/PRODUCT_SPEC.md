# 产品规格

## 产品定位

AKK 菌配方自动生成可视化平台服务于内部食品研发人员。平台帮助研发人员基于 AKK 菌产物性质、目标食品应用、目标性质和限制条件，快速形成候选研发方向。

系统第一版的价值不是替代实验，而是把已有规则、产物属性和研发约束组织成一个可交互的探索工具。

## 第一版边界

- 平台只用于内部研发。
- 生成结果必须标记为“研发实验建议”。
- 不输出可直接上市的最终食品配方。
- 所有预测结果必须包含置信度、风险提示和需要验证的实验指标。
- 第一版使用 mock 数据和规则模板。
- 第一版不接真实大模型、不接真实数据库、不做登录系统。

## 目标用户

食品研发人员，尤其是需要评估 AKK 菌产物在不同食品应用中可行性的配方研发、工艺验证和项目评估人员。

## 核心业务流程

1. 用户进入 Dashboard，查看当前 mock 数据概览和研发提示。
2. 用户进入 AKK 产物库，浏览产物的基础性质、功能标签和适用场景。
3. 用户打开产物详情，查看单个产物的关键性质、风险项和建议验证指标。
4. 用户进入配方生成页面，选择目标食品应用，输入目标性质和限制条件。
5. 系统根据 mock 数据和规则模板生成候选配方。
6. 用户进入配方结果页面，查看候选配方、份额配比、预测结果、置信度、风险提示和实验验证建议。

## 第一版功能范围

### Dashboard

展示平台概览，包括 mock 产物数量、可用食品应用、最近生成记录、风险提示摘要和研发边界声明。

### AKK 产物库

展示 AKK 菌产物列表。每个产物包含名称、类别、关键性质、适用食品应用、风险标签和推荐验证指标。

### 产物详情

展示单个 AKK 菌产物的详细说明，包括性质说明、功能假设、适用范围、限制条件、风险提示和实验验证建议。

### 配方生成

用户选择目标食品应用，并输入目标性质和限制条件。第一版使用固定字段和 mock 选项，不使用自由大模型推理。

### 配方结果

展示多个候选配方。每个候选配方必须包含：

- “研发实验建议”标签
- 份额配比
- 预测结果
- 置信度
- 风险提示
- 需要验证的实验指标
- 下一步实验建议

## 非目标

第一版不实现以下内容：

- 用户登录和权限
- 真实数据库
- 真实文献检索
- 真实大模型调用
- 真实预测模型调用
- 真实配方引擎
- 可上市配方审批流程
- 生产工艺参数自动生成
