# STEP122：实验文件血缘保护与可视化

## 交付内容

- 原始设备文件一旦存在结构化派生资产，不能被直接删除；
- 删除请求返回 HTTP 409，并列出仍依赖该原始证据的派生资产编号；
- 研发人员必须先处置派生资产，才能移除原始文件，避免数据血缘断裂；
- 实验详情页的“最近上传文件资产”新增“来源链路”列：
  - 原始二进制文件显示“原始证据，待转换”；
  - CSV/XLSX 派生文件显示其对应的原始设备文件；
  - 未关联来源的文件标记为“独立上传”；
- 文件状态以中文业务语言呈现为“待设备适配”或“已解析”。

## 验证记录

- 新增删除保护回归用例，确认原始文件被引用时删除返回 `409`；
- 文件上传专项：`25 passed`；
- 后端完整测试：`352 passed, 1 skipped`；
- 前端 `typecheck` 与生产构建通过；
- 演示主链路检查通过：实验归档、数据分析、仿真、优化和报告数据包均可用。
