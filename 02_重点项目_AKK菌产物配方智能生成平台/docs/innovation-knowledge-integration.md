# 创新点附件知识接入说明

本文件记录“创新点附件”进入 AKK 菌配方自动生成平台后的知识结构和算法口径。第一版仍为内部研发实验建议，不输出最终生产配方、真实产线控制指令或上市功效承诺。

## 已吸收的核心知识

1. 海藻功能碳源新范式
   - 平台不再只把海藻成分当作普通配料，而是作为 Akk 菌可利用、可筛选、可优化的功能碳源。
   - 已纳入红毛藻多糖、超高压改性红毛藻多糖、λ-卡拉胶、ι-卡拉胶、岩藻聚糖、紫菜糖蛋白、桔梗多糖和琼胶。

2. 红毛藻多糖剂量窗口
   - 附件材料显示红毛藻多糖在约 0.5-2.0 g/L 区间对 Akk 增殖、粘附和短链脂肪酸表现有支撑价值。
   - 平台将 2.0 g/L 作为 BFP 默认优化中心，并对超出有效窗口的输入降低置信度。

3. λ-卡拉胶与 Amuc-1260 / 特征代谢物方向
   - λ-卡拉胶被建模为更偏向特征代谢物与 Amuc-1260 激活验证的碳源。
   - 平台在该方向自动加入 Amuc-1260、特征代谢物、短链脂肪酸、黏度和分子量分布等验证指标。

4. 工艺链升级
   - 附件强调“海藻原料处理 - Akk 定向发酵 - 灭活/冻干/包埋 - 产品基质适配”的协同制造链。
   - 平台已将预处理、压力、搅拌、分子量预测和包埋稳定性纳入评分。

5. 产品转化场景
   - 红藻多糖鱼丸、后生元冻干粉、包埋颗粒和培养液被作为不同产品形态处理。
   - 不同产品形态会改变碳源最佳浓度、稳定性权重、成本友好性和验证指标。

## 已落地到算法的能力

- `CarbonSourceProfile`：每种碳源拥有名称、类别、最佳浓度、有效窗口、增殖因子、SCFA 因子、粘附因子、屏障因子、分子量偏移、工艺说明、证据说明和验证重点。
- `dose_response`：根据碳源和产品形态计算剂量响应曲线。
- `molecular_weight_prediction`：根据碳源、压力、搅拌和预处理状态预测分子量窗口。
- `pretreatment_effect`：把预处理、超高压、搅拌剪切等工艺因素转成增益或风险。
- `validation_indicators`：根据碳源和产品形态自动生成验证指标。
- 仿真总分：综合 Akk 增殖、短链脂肪酸、屏障/粘附、分子量适配和稳定性。

## 当前置信度边界

- 红毛藻多糖、λ-卡拉胶、UBFP：可作为第一版重点展示方向。
- ι-卡拉胶：适合凝胶/果冻/软糖等基质适配，但需要更强分子量和质构数据。
- 岩藻聚糖、紫菜糖蛋白：作为前沿储备方向，当前应降低自动推荐置信度，优先用于探索。
- 所有结果必须经过小试、中试和人工审核。
