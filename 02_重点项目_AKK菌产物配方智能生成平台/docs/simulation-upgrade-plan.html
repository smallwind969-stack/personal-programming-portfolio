新仿真引擎 替换方案

核心改造：SimulationService.predict()

删除 _predict_scores 全部规则公式，改为调用已训练的sklearn模型。没有已晋升模型时，返回"请先完成数据分析并训练模型"，而不是假装预测。

class SimulationService: def predict(self, request, experiment_id=None): # ── 删除全部规则公式 ── # scores = self._predict_scores(request) ← 删 # recommended = self._recommended_settings(...) ← 删 # risks = self._risks(...) ← 删 # confidence = self._confidence(...) ← 删 # curve = self._dose_curve(...) ← 删 # ── 新逻辑：必须走模型 ── if experiment_id is None: raise ValueError("仿真预测需要指定实验工作区") record = self.registry.latest(experiment_id) if record is None or record.status != "approved": raise ValueError( "没有可用的已晋升模型。请先完成数据分析流程，" "训练模型并通过人工验收。" ) # 特征绑定：仿真参数 → 模型输入 features = self.binding_service.bind(experiment_id, request.to_params()) # 模型推理 prediction = self.inference_service.predict(record, features) # 预测区间（来自模型评估报告） report = self.evaluation_service.latest_report(experiment_id) interval = report.prediction_interval # 真实95%区间 # 外推检测 extrapolation = self.check_extrapolation(record, features) return SimulationPredictResponse( predictions=prediction, confidence=report.reliability_score, # 来自真实评估 predictionInterval=interval, extrapolationWarning=extrapolation, modelVersion=record.modelVersion, label="研发实验建议", )
关键设计决策：没有模型就不能预测。这是正确的——宁可让用户知道"需要先训练模型"，也不要用假公式骗人。你们是自有产线，数据是现成的，训练模型不是问题。

新优化引擎 替换方案

核心改造：OptimizationOrchestrator._candidates()

删除3套硬编码方案和规则评分公式。改为基于已晋升模型的参数空间搜索。

class OptimizationOrchestrator: def _candidates(self, experiment_id, strategy): # 删除：硬编码3套方案参数 # 删除：scoreBreakdown / predictionIntervals 硬编码 # 删除：responseSurface = score - abs(dt)*1.6 - abs(dp)*8 # 删除：baselineImprovements 硬编码 # ── 新逻辑：模型驱动的参数搜索 ── record = self.registry.latest(experiment_id) binding = self.binding_service.get_binding(experiment_id) # 1. 从特征绑定获取参数范围 ranges = binding.parameter_ranges # temperature: [30, 45], ph: [5.5, 8.0], ... # 2. 定义搜索策略（从数据库读取权重，不硬编码） strategy_config = self.db.get_strategy(strategy) # yieldPriority: {yield: 1.0} # balanced: {yield: 0.55, stability: 0.25, cost: 0.20} # energySaving: {yield: 0.45, cost: 0.55} # 3. 网格搜索（粗筛） grid = self.build_grid(ranges, steps_per_dim=8) # 8^4 = 4096 个组合（vs 当前 3^3 = 27） candidates = [] for params in grid: features = binding.transform(params) if self.is_extrapolated(record, features): continue pred = self.inference.predict(record, features) score = self.compute_objective(pred, strategy_config) candidates.append((params, pred, score)) # 4. 取Top-3 candidates.sort(key=lambda c: c[2], reverse=True) top3 = candidates[:3] # 5. 对Top-3做精细搜索（局部优化） refined = [] for params, pred, score in top3: local_best = self.local_search(params, record, binding, strategy_config) refined.append(local_best) return self.build_candidate_plans(refined, strategy)

新7阶段管道 自动化

核心改造：SimulationRunOrchestrator.advance()

删除手动推进和硬编码状态更新。改为一次性自动执行7阶段管道，每个阶段有真实计算。

class SimulationRunOrchestrator: def run_pipeline(self, experiment_id, params): """一次性自动执行7阶段，不需要手动推进""" run = self.create(experiment_id, params) try: for stage in run.stages: run = self._execute_stage(run, stage) self._persist(run) run.status = "completed" except StageFailure as e: run.status = "failed" run.failureReason = str(e) return run def _execute_stage(self, run, stage): """每个阶段有真实计算，不是空壳""" if stage.stageId == "model-validation": result = self._validate_model(run) elif stage.stageId == "system-initialization": result = self._init_system(run) elif stage.stageId == "material-preparation": result = self._prepare_materials(run) elif stage.stageId == "core-production": result = self._run_fermentation(run) elif stage.stageId == "downstream-processing": result = self._run_downstream(run) elif stage.stageId == "product-collection": result = self._collect_products(run) elif stage.stageId == "result-evaluation": result = self._evaluate_results(run) stage.status = "completed" stage.outputSummary = result.summary stage.modelBasis = result.evidence return run

7阶段真实计算内容

阶段当前（删）升级后（新）
① 模型校验 硬编码输出文本 检查模型版本+特征范围+外推检测，输出校验报告
② 系统初始化 硬编码设备快照 从数据库加载设备能力模板，计算物料需求量
③ 原料准备 硬编码输出文本 物料衡算（碳源用量=浓度×体积），成本核算（单价×用量）
④ 核心发酵 调用_predict_scores规则公式 调用sklearn模型推理，生成过程曲线（温度/pH/OD vs 时间）
⑤ 下游处理 硬编码输出文本 收率模型（数据库配置），活性保留率计算
⑥ 产物收集 硬编码输出文本 最终产物量=发酵产物×下游收率，质量检测判定
⑦ 结果评估 硬编码置信度 聚合模型评估报告的置信度+外推风险+验证指标
