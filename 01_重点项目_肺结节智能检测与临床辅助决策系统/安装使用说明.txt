================================================================================
              肺部CT智能辅助诊断系统 - 安装使用说明
================================================================================

本系统包含两个独立组件：
  1. FJJ System - CT影像自动检测与识别系统（Web应用）
  2. Dicom.annotator - 肺结节标注工具（桌面应用）

================================================================================
一、FJJ System 自动检测与识别系统
================================================================================

【系统介绍】

FJJ System是一个基于深度学习的肺部CT智能诊断Web系统，提供：
  → 自动检测CT影像中的肺结节
  → 智能判别结节良恶性
  → 可视化诊断界面
  → 检测结果报告导出

【环境要求】

  Python版本：3.9+
  操作系统：Windows 10/11
  内存：8GB以上
  显存：6GB以上（可选，用于GPU加速）

【安装步骤】

步骤1：进入项目目录
  cd "FJJ System"

步骤2：安装Python依赖
  pip install -r requirements.txt

  主要依赖包括：
    - flask          Web框架
    - torch          深度学习框架
    - SimpleITK      医学影像处理
    - numpy          数值计算
    - Pillow         图像处理
    - scipy          科学计算
    - scikit-image   图像处理

步骤3：准备模型权重文件

  将以下三个模型文件放入 models/ 文件夹：
    ├── vnet_v6_7_sprint_recall_0.9648_epoch_41.pth  (VNet检测模型)
    ├── fpr_v7_best_rec_0.9612.pth                   (ResNet精筛模型)
    └── GOLDEN_Ep58_A0.923.pth                       (双分支分类模型)

步骤4：启动系统
    命令行启动
    python app2.py

  启动成功后显示：
    >>> 当前 app2.py 路径: ...
    >>> CSV 保存路径: ...
     * Running on http://127.0.0.1:5001

步骤5：访问系统

  打开浏览器访问：http://127.0.0.1:5001

【使用流程】

  1. 上传CT影像
     → 点击左侧"+ 上传 DICOM 序列"按钮
     → 选择包含DICOM文件的文件夹
     → 等待上传和处理完成

  2. 结节检测
     → 点击"第一步：结节检测"按钮
     → 系统自动扫描并标记可疑结节
     → 等待检测完成（约20-40秒）

  3. 性质识别
     → 点击"第二步：性质识别"按钮
     → 系统判断每个结节的良恶性
     → 查看结果：红色=恶性，蓝色=良性

  4. 查看结果
     → 点击结果列表中的结节项，自动跳转到对应层级
     → 使用滑块或滚轮浏览不同层级
     → 调节窗宽窗位查看不同组织

  5. 导出报告
     → 点击"下载报告"按钮导出诊断结果

【界面功能】

  左侧面板：
    - 病例列表：显示已上传的所有病例
    - 上传按钮：上传新的DICOM序列

  中间区域：
    - CT图像显示：支持缩放、平移
    - 层级切换：滚轮、滑块、按钮
    - 标注框显示：检测结果可视化

  右侧面板：
    - 窗宽窗位调节：调节显示效果
    - 检测按钮：触发AI检测
    - 识别按钮：触发良恶性判别
    - 结果列表：显示检测结果

【输出文件】

  uploads/              上传的原始DICOM文件
  static/processed/     生成的预览切片PNG
  timing_results.csv    性能时间记录

================================================================================
二、Dicom.annotator 肺结节标注工具
================================================================================

【系统介绍】

Dicom.annotator是一个用于肺结节人工标注的桌面工具，主要用于：
  → 为深度学习模型训练准备标注数据
  → 对CT影像中的肺结节进行精确标注
  → 导出标准格式的训练数据

【环境要求】

  Python版本：3.9+
  操作系统：Windows 10/11

【安装步骤】

步骤1：安装依赖

  pip install pydicom
  pip install PyQt6
  pip install numpy
  pip install pandas
  pip install Pillow

步骤2：运行标注工具

  python dicom.annotator5.2(1).py

  启动后显示主窗口

【使用流程】

  1. 打开DICOM序列
     → 点击"打开DICOM文件夹"按钮
     → 选择包含DICOM文件的文件夹
     → 系统自动加载并显示第一张切片

  2. 选择标注类型

     四种标注类型：
       → 非肿瘤性（绿色）：良性病变
       → 癌前病变（黄色）：不典型腺瘤样增生、原位腺癌
       → 肿瘤性病变（红色）：恶性肿瘤
       → 无法确定（蓝色）：待定

  3. 进行标注
     → 在图像上按住鼠标左键拖动绘制矩形框
     → 松开鼠标完成标注
     → 标注框会显示在图像上

  4. 浏览和修改
     → 使用滑块或按钮切换不同切片
     → 查看当前层面的所有标注
     → 点击"清除当前层面所有标注"可删除

  5. 保存标注结果
     → 点击"保存标注(CSV)"按钮
     → 选择保存位置和文件名
     → 标注结果保存为CSV格式

【CSV输出格式】

  标注结果CSV包含以下字段：
    - series_uid      序列唯一标识
    - display_id      显示ID
    - slice_index     切片索引
    - x_min, y_min    矩形左上角坐标
    - x_max, y_max    矩形右下角坐标
    - label           标签值(0/1/2/-100)
    - label_chinese   中文标签名称
    - label_english   英文标签名称

【界面功能】

  左侧区域：
    - CT图像显示
    - 标注框叠加显示
    - 层级切换滑块

  右侧面板：
    - 文件操作按钮
    - 序列信息显示
    - 标注类型选择
    - 清除标注按钮

【操作技巧】

  → 绘制矩形时，按住左键拖动
  → 矩形大小需>5像素才会被记录
  → 标注框颜色对应不同类型
  → 可随时切换标注类型
  → 每个层面的标注独立存储

三、常见问题与解决方案
================================================================================

【问题1】启动时提示"ModuleNotFoundError"

  原因：依赖包未安装
  解决：pip install -r requirements.txt

【问题2】启动时提示"模型文件不存在"

  原因：模型权重文件未放入models文件夹
  解决：将三个.pth文件放入FJJ System/models/目录

【问题3】检测时间过长

  原因：使用CPU推理
  解决：安装CUDA版本的PyTorch
        pip install torch --index-url https://download.pytorch.org/whl/cu121

【问题4】显存不足

  原因：GPU显存太小
  解决：使用CPU模式
        修改app2.py中 DEVICE = torch.device("cpu")

【问题5】DICOM文件无法加载

  原因：文件格式不支持或文件损坏
  解决：确认文件为标准DICOM格式(.dcm)

【问题6】中文显示乱码

  原因：终端编码问题
  解决：运行前执行 set PYTHONUTF8=1
        或使用run.bat启动脚本

【问题7】前端无法访问

  原因：端口被占用
  解决：修改app2.py最后一行的端口号
        app.run(host='127.0.0.1', port=5002)
