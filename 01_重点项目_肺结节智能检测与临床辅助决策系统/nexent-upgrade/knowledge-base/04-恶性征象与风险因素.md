# 恶性影像征象与危险因素

## 一、提示恶性的影像征象

| 征象 | 说明 |
|---|---|
| **毛刺征（spiculation）** | 结节边缘放射状细线样突起，提示浸润性生长，恶性可能性高 |
| **分叶征（lobulation）** | 结节边缘呈分叶状，反映肿瘤不均匀生长 |
| **胸膜牵拉征（pleural indentation）** | 结节与胸膜间的线状牵拉，常见于腺癌 |
| **空泡/空洞征（cavitation）** | 结节内透亮区，需结合壁厚、内壁是否光整判断 |
| **血管集束征** | 血管向结节聚集 |
| **支气管截断/含气支气管征** | 支气管在结节处中断或走行其中 |

> 出现上述可疑征象时，应提高医生复核优先级，但不等于确诊恶性。

## 二、患者危险因素
- **年龄**：≥ 50 岁风险升高。
- **吸烟史**：当前吸烟或既往长期吸烟是重要危险因素。
- **肿瘤史**：既往恶性肿瘤病史。
- **家族史**：肺癌家族史。
- **职业暴露**：石棉、氡、重金属等接触史。

## 三、动态变化的意义
- **增大**：实性结节直径增大、磨玻璃出现实性成分或实性成分增多，均提示风险上升。
- **稳定**：长期稳定（尤其磨玻璃结节稳定 ≥ 5 年）通常提示惰性或良性。
- **新发**：随访中新出现的结节需重新评估。

## 四、综合评估思路
1. 先补齐结节**最大径**与**结节类型**（实性/磨玻璃/部分实性）。
2. 记录可疑**影像征象**。
3. 结合患者**危险因素**与**既往 CT 对比**。
4. 套用 Fleischner 2017（偶发）或 Lung-RADS（筛查）给出随访建议。
5. 最终由医生确认并决定处理方案。
