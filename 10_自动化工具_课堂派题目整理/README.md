# 课堂派题目整理工具

我使用 PyQt5、Playwright 和结构化解析实现授权页面登录、批量采集、题型识别、去重及 Excel/Word 导出。

## 重要合规声明

本软件仅用于整理您本人账号登录后已经有权限查看的课程、作业、测验或练习页面中的题目信息。

**使用本软件时，请务必遵守以下合规要求：**

1. ✅ **只访问本人有权限的页面** - 仅整理您本人账号登录后可见的内容
2. ✅ **不绕过验证机制** - 不绕过验证码、登录限制、接口签名或任何反爬机制
3. ✅ **不扫描未授权资源** - 不扫描课程ID、题库ID、用户ID
4. ✅ **合理延迟** - 页面间自动延迟，避免高频请求
5. ✅ **不破解答案** - 只整理页面中正常可见的信息，不获取隐藏答案
6. ✅ **不保存密码** - 登录通过浏览器手动完成，只保存浏览器登录状态

## 使用步骤

### 启动软件

```bash
python main.py
```

软件启动后会显示图形界面，分为左侧操作步骤和右侧配置日志区域。

### 步骤1: 登录

1. 点击"打开课堂派并登录"按钮
2. 浏览器窗口自动打开课堂派网站
3. 在浏览器中手动完成登录（输入用户名、密码、验证码等）
4. 登录成功后，回到软件点击"保存当前登录状态"
5. 登录状态保存到 `data/auth.json` 文件

**注意：**
- 不要将用户名和密码写在代码中
- 登录状态有效期有限，过期后需重新登录

### 步骤2: 添加页面链接

在文本框中输入您要整理的课堂派页面链接，每行一个URL：

```
https://ketangpai.com/#/class_studentTestDetail?testpaperid=xxx
https://ketangpai.com/#/class_studentTestDetail?testpaperid=yyy
```

也可以：
- 点击"从txt导入"从文本文件导入链接
- 点击"保存到txt"保存链接列表
- 点击"清空"清空链接

**重要提示：**
- 只填写您本人账号登录后有权限查看的页面链接
- 不要填写其他人的课程或未授权的页面
- 以 `#` 开头的行将被忽略

### 步骤3: 配置导出设置

在右侧配置区域：

1. **导出格式**：勾选Excel或Word（可同时勾选）
2. **保存位置**：点击"选择..."选择保存目录，默认为 `output` 目录
3. **页面间隔**：设置每个页面间的等待秒数，默认3秒
4. **自动滚动**：勾选后自动滚动页面加载全部内容
5. **导出raw_text**：勾选后Excel中包含原始文本列，方便校对

### 步骤4: 开始整理

1. 点击"开始整理"按钮
2. 观察进度条和日志输出
3. 整理完成后会弹窗提示，显示导出文件路径

## 导出文件说明

### Excel文件 (questions.xlsx)

包含以下列：

| 列名 | 说明 |
|------|------|
| 序号 | 题目序号 |
| 来源页面 | 页面URL |
| 题型 | 单选题/多选题/判断题等 |
| 题干 | 题目文本 |
| 选项 | 选项内容（多行分隔） |
| 可见答案 | 页面正常显示的答案 |
| 解析 | 页面正常显示的解析 |
| 原始文本 | 题目块的完整文本 |

**Excel格式特点：**
- 第一行加粗并冻结
- 自动调整列宽
- 文本自动换行
- 自动去重

### Word文件 (questions.docx)

每道题格式：

```
第 1 题【单选题】
来源页面：xxx

题干：
xxxx

选项：
A. xxx
B. xxx

答案：
xxx

解析：
xxx

──────────────────────────────────────────────────
```

## 如何调整CSS选择器

如果课堂派页面结构变化导致题目提取不准确，可以调整解析器中的CSS选择器。

### 步骤：

1. 在浏览器中打开课堂派页面
2. 右键点击题目 → 选择"检查"（或按F12）
3. 在开发者工具中查看题目的HTML结构
4. 找到题目容器的 `class` 名称
5. 打开 `parser.py` 文件
6. 找到 `QUESTION_CONTAINER_SELECTORS` 列表
7. 将新的选择器添加到列表中

### 示例：

如果检查元素发现题目容器的class是 `.exam-problem`，则修改：

```python
QUESTION_CONTAINER_SELECTORS = [
    ".exam-problem",  # 新增的选择器
    ".question-item",
    ".question",
    # ... 其他选择器
]
```

## 常见问题

### Q1: 提示"未找到登录状态文件"

**原因：** 未保存登录状态或登录状态已过期

**解决：** 重新执行登录步骤（步骤1）

### Q2: 提取不到题目或提取不准确

**原因：** 课堂派页面结构变化，选择器不匹配

**解决：** 参考上方"如何调整CSS选择器"章节调整选择器

### Q3: 软件运行缓慢

**原因：** 为避免高频请求，每个页面间有延迟

**说明：** 这是合规要求，不能移除延迟

### Q4: 导出的答案为空

**原因：** 页面未显示答案

**说明：** 本软件只提取页面正常可见的答案，不会尝试破解隐藏答案

## 技术栈

- **GUI框架**: PySide6 (Qt for Python)
- **浏览器自动化**: Playwright
- **HTML解析**: BeautifulSoup4 + lxml
- **Excel导出**: pandas + openpyxl
- **Word导出**: python-docx
