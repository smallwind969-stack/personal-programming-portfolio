# 多机器人巡检优化

2026 高教社杯数学建模 B 题的可执行算法实现，围绕固定监测点、无线电干扰源定位、信息增益驱动检测和多机器人路径规划展开。

## 核心思路

- 将每个频道维护为未知、活动、已定位或已清除状态。
- 用空间网格表示干扰源位置与作用半径的联合可行域。
- 以观测熵下降量计算候选监测动作的期望信息增益。
- 综合移动时间、检测时间、切换频道成本和信息收益选择下一动作。
- 当可行域能够被清除半径覆盖时，转入确定性清除流程。
- 问题 4 在此基础上加入多机器人协同、联合测点与巡检路径优化。

## 运行

需要 Python 3.10 及 NumPy：

```bash
pip install numpy
python problem3_robot_final.py
python problem4_robot_final.py
```

`robot_b3/` 保留了模块化版本及相关验证脚本。程序运行时读取题目输入或内置示例，并输出监测、定位和清除动作序列。
