# 智慧校园图算法实验平台

这是一个工程化的数据结构课程设计项目。项目以校园导航为场景，把校园地点抽象为图的顶点，把道路抽象为图的边，实现最短路线查询、应急路线推荐、多源路径查询、图遍历、最小道路改造方案、地图可视化和自动化测试。

## 功能亮点

- 从数据文件加载校园地点和道路。
- 使用迪杰斯特拉算法查询加权最短路线。
- 使用启发式寻路思想完成基于坐标的应急路线搜索。
- 使用弗洛伊德算法完成任意两点路线查询。
- 支持广度优先搜索和深度优先搜索遍历。
- 使用克鲁斯卡尔算法和普里姆算法生成最小道路改造网络。
- 使用并查集支撑克鲁斯卡尔算法。
- 自动导出校园地图和路线分析报告。
- 提供核心算法回归测试。

## 项目结构

```text
SmartCampus_GraphLab/
  include/smartcampus/     公共头文件
  src/                     算法实现与菜单程序
  tests/                   算法测试
  data/                    校园地图数据
  docs/                    课程报告和系统设计说明
  output/                  生成的地图和报告
  build.bat                编译脚本
  test.bat                 测试脚本
  run.bat                  运行脚本
  CMakeLists.txt           可选构建配置
```

## 编译、运行和测试

在当前目录打开终端：

```bat
build.bat
run.bat
test.bat
```

推荐演示输入：

- 起点编号：`1`，代表学校正门
- 终点编号：`8`，代表学生宿舍

自动演示脚本：

```bat
scripts\export_demo.bat
```

运行后会生成：

- `output/route_report.md`
- `output/campus_map.svg`
- `output/campus_map.png`

课堂演示时可以直接在菜单中选择 `8`，系统会自动打开校园地图图片，便于老师对照地点编号和道路权值理解最短路径。

## 课程要求对应关系

- 图的存储：邻接表和边表。
- 路径算法：迪杰斯特拉算法、启发式寻路算法、弗洛伊德算法。
- 遍历算法：广度优先搜索、深度优先搜索。
- 最小生成树：克鲁斯卡尔算法、普里姆算法。
- 文件存储：校园地点和道路数据文件。
- 测试内容：合法数据、路径一致性、遍历完整性、最小生成树正确性。
- 报告内容：需求分析、概要设计、详细设计、运行测试、总结心得。
