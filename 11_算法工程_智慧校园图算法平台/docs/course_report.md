# 数据结构与算法设计课程设计报告

## 一、项目概述

项目名称为“智慧校园图算法实验平台”。系统以校园地图为背景，将校园地点抽象为图的顶点，将道路抽象为图的边，支持最短路径查询、应急路径推荐、校园道路改造最小成本方案、图遍历演示和多源路径查询。

该项目对应课程设计参考题中的校园导航、最小生成树、图的遍历、并查集等方向，但实现方式不是单一算法演示，而是一个具有工程结构、数据文件、自动测试和可视化输出的小型算法平台。

## 二、需求分析

系统需要完成以下功能：

1. 从数据文件读取校园地点和道路信息。
2. 查询任意两个地点之间的最短路径。
3. 支持基于坐标启发式的应急路径搜索。
4. 支持弗洛伊德多源最短路径查询。
5. 支持广度优先搜索和深度优先搜索遍历校园图。
6. 使用克鲁斯卡尔算法和普里姆算法生成校园道路改造的最小生成树。
7. 将路线和最小生成树导出为路线报告和校园地图。
8. 对核心算法进行自动化测试。

## 三、概要设计

系统采用分层架构：

- 数据层：保存校园地点和道路数据。
- 图模型层：负责地点、道路和邻接表。
- 算法层：实现迪杰斯特拉算法、启发式寻路算法、弗洛伊德算法、广度优先搜索、深度优先搜索、普里姆算法和克鲁斯卡尔算法。
- 输出层：输出路线报告和校园地图。
- 交互层：提供菜单式交互。

这种结构使算法与界面解耦，便于测试和扩展。

## 四、详细设计

### 4.1 图存储结构

系统使用邻接表作为主要存储结构。邻接表适合路径搜索和遍历，因为只需要访问当前地点周围的道路，不必扫描完整矩阵。

系统同时保存原始边表。边表适合克鲁斯卡尔算法按权值排序，也适合地图绘制时遍历所有道路。

### 4.2 最短路径算法

迪杰斯特拉算法使用优先队列维护当前最短距离，适合边权均为正数的校园道路网络。启发式寻路算法在迪杰斯特拉算法的基础上加入欧氏距离估计函数，使其在有坐标信息的地图上更贴近真实导航系统。

### 4.3 多源路径算法

弗洛伊德算法使用矩阵存储任意两点间最短距离，并维护路径还原矩阵。该算法适合地点数量较少但查询频繁的场景。

### 4.4 最小生成树

克鲁斯卡尔算法使用并查集判断连通分量，按边权从小到大选择道路；普里姆算法使用优先队列从一个起点逐步扩展。二者都可用于“以最低成本连通校园主要地点”的道路改造规划。

## 五、运行与测试

测试覆盖内容：

- 迪杰斯特拉算法能找到加权最短路径。
- 启发式寻路算法与迪杰斯特拉算法的结果一致。
- 克鲁斯卡尔算法能生成正确的最小生成树。
- 广度优先搜索和深度优先搜索能访问所有可达地点。
- 弗洛伊德算法能查询并还原路径。

运行测试：

```bat
test.bat
```

运行系统：

```bat
run.bat
```

## 六、项目创新点

1. 一个项目整合多种图算法，不局限于单一题目。
2. 使用工程化目录结构，头文件、实现、测试、数据和文档分离。
3. 自动生成校园地图，使算法结果可视化。
4. 自动生成路线报告，便于课程汇报和演示。
5. 同时实现克鲁斯卡尔算法和普里姆算法，便于比较两种最小生成树思路。

## 七、总结与心得

通过本项目，我不仅复习了图、队列、栈、优先队列、并查集、矩阵等数据结构，也进一步理解了算法与工程设计之间的关系。一个优秀的课程设计不应只是把算法写出来，而应关注数据来源、模块边界、异常处理、测试验证和演示效果。

本项目将课堂上的图算法应用到智慧校园场景中，既满足课程要求，也具有较强的展示价值。
