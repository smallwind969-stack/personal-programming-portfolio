# 智慧校园图算法实验平台系统设计说明

## 一、总体架构

系统分为四层：

1. 数据层：用数据文件保存校园地点和道路。
2. 图模型层：图结构负责管理地点、道路和邻接表。
3. 算法层：路径查询、图遍历和最小生成树算法都基于统一图接口实现。
4. 展示层：提供控制台菜单、路线分析报告和校园地图导出。

这种结构让算法与界面解耦。更换地图数据、增加新算法或调整菜单时，不需要破坏已有模块。

## 二、数据结构设计

- 映射表：按地点编号保存地点信息，便于快速查询。
- 邻接表：保存每个地点可直接到达的相邻地点，适合路径搜索和图遍历。
- 边表：保存全部道路，适合最小生成树和地图绘制。
- 优先队列：用于迪杰斯特拉算法、启发式寻路算法和普里姆算法。
- 普通队列：用于广度优先搜索。
- 栈：用于非递归深度优先搜索。
- 并查集：用于克鲁斯卡尔算法判断连通分量。
- 二维矩阵：用于弗洛伊德算法保存任意两点间最短距离。

## 三、算法复杂度

| 算法 | 用途 | 时间复杂度 |
| --- | --- | --- |
| 迪杰斯特拉算法 | 单源最短路线 | O((V + E) log V) |
| 启发式寻路算法 | 应急路线推荐 | O((V + E) log V) |
| 弗洛伊德算法 | 多源路线查询 | O(V^3) |
| 广度优先搜索 | 可达性和层次遍历 | O(V + E) |
| 深度优先搜索 | 连通遍历 | O(V + E) |
| 克鲁斯卡尔算法 | 最小道路改造网络 | O(E log E) |
| 普里姆算法 | 最小道路改造网络 | O(E log V) |

## 四、工程化设计

- 使用头文件和实现文件分离，降低模块耦合。
- 使用独立测试程序验证核心算法。
- 使用数据文件驱动校园地图，便于修改和扩展。
- 使用脚本完成编译、测试、运行和自动演示。
- 导出地图和报告，让课程展示更直观。
